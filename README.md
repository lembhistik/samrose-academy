# Samrose's Academy Design

Create a luxury, modern, and prestigious educational website for "SAMROSE'S ACADEMY". The visual system must directly match the brand colors from the official logo: Deep Navy/Indigo (#212246), Vibrant Crimson Red (#E52E35), Soft Slate Gray (#F1F5F9), and Pure White (#FFFFFF). The design must look authoritative, clean, and welcoming for families.

Design & Aesthetic Rules for Lovable:

Primary Color: Deep Navy (#212246)

Accent Color: Crimson Red (#E52E35)

Background Colors: Pure White (#FFFFFF) & Soft Slate (#F1F5F9)

Typography: Serif font for headers (Playfair Display or Cinzel) and clean sans-serif (Inter) for body text to maintain an academic, prestigious feel
